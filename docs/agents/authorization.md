# Authorization boundary（授权边界）

> 本环境：审批策略 = never、文件策略 = danger-full-access（沙箱不拦任何路径）。
> 没有外部护栏，本文件是 agent 会话内授权的唯一依据；与全局 Windows Agent 规范
> "破坏性 / 高风险分级确认"条款冲突时，本文件更严、从本文件。

## 1. 触发授权（汇报 → 等明确同意 → 执行 → 回执）

### 1.1 不可逆 / 破坏性

- 删除：无 git 跟踪且不可再生成的文件/目录（日志、用户数据、未跟踪脚本、%TEMP% 非本会话文件等）
- 覆盖：无 git 跟踪且不可再生内容的覆盖
- 格式化 / 磁盘级操作
- `git reset --hard` / `checkout .` 丢弃未提交的本地改动
- 批量（≥3 个对象）删除 / 改名 / 移动（汇报附完整清单预览：路径 / 数量 / 目标）
- push 到远端、打 tag、删远端分支/标签、对外发布（push 另见 AGENTS.md 红线 7）

### 1.2 工作区外写改

- 工作区 = `G:\Dev\agent\dsh plugins\dsh-file-picker`
- 工作区之外的任何创建 / 修改 / 删除（C 盘、`~/.dsh`、其他项目……），无论文件工具还是 pwsh 命令
- 例外：%TEMP% 下本会话 / 本插件创建的一次性临时文件——写入、删除、清理均免授权

### 1.3 汇报模板（四段，每项必填）

1. 原因——为什么必须做（不做的后果）
2. 预计结果——本应产生的确定输出
3. 可能的结果——失败 / 意外风险面与失败后状态
4. 产生的影响——影响范围（文件 / 进程 / 远端）、是否可回退、如何回退

### 1.4 回路

- 汇报 → 等待你的明确同意（文字授权）→ 才执行
- 未收到明确同意不执行；不设超时自动执行
- 被拒或要求修改：按反馈调整或放弃，不换花样重试同一操作
- 执行后回执：实际结果（与预计是否一致、有无偏差）

## 2. 免授权（正常开发，直接做）

- 工作区内一切 git 可逆操作：编辑 / 覆盖已跟踪代码与文档、删除已跟踪文件、新建文件（代码 / 文档 / 临时诊断）
- 构建 / 测试：`pnpm build`、`vitest`、`pnpm install` / `pnpm add`（lock 入 git、可再生）
- 本地 `git commit`（可 reset 回退）
- 工作区内删除本会话刚创建、未跟踪、用完即弃的临时诊断文件
- 工作区外的一切读取（日志、配置、交接文档、%TEMP% 只读）
- 系统只读查询（进程、服务状态）

## 3. 判定轴

位置（工作区内 / 外） + 是否可逆（git 可恢复或可再生 → 免授权；否则 → 授权）。
两者满足其一即触发；读取一律豁免。
