# Issue tracker

此仓库的 issue 跟踪在 GitHub Issues（github.com/JackeyWilder/dsh-file-picker）。

- 建票：`gh issue create`（默认拉当前分支为上下文源）。
- 读写票的技能（to-tickets / triage / to-spec / qa）一律经 `gh issue <command>` 操作 origin 远端。
- 不使用 `.scratch/` 本地 markdown 跟踪器。
